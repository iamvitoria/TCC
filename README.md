## 🚀 Sobre o Projeto

O **EcoMonitor** é uma aplicação web progressiva (PWA) desenvolvida como parte do Trabalho de Conclusão de Curso (TCC) em Sistemas de Informação. 

O objetivo do projeto é utilizar a **gamificação** para engajar usuários na preservação ambiental, permitindo o registro de ocorrências, acompanhamento de impacto positivo e desbloqueio de conquistas baseadas em ações sustentáveis.

Embora seja uma aplicação Web (acessível via navegador), o layout foi desenvolvido com a metodologia **Mobile-First**, simulando a experiência de um aplicativo nativo.

## ✨ Funcionalidades

* **📱 Interface Mobile-First:** Design responsivo focado na experiência em dispositivos móveis.
* **🎮 Gamificação:** Sistema de níveis (XP), barra de progresso e medalhas (conquistas) desbloqueáveis.
* **❤️ Contribuições:** Histórico visual do impacto positivo e doações realizadas pelo usuário.
* **⭐ Avaliação:** Sistema interativo de feedback com classificação por estrelas.
* **🔐 Autenticação:** Interfaces simuladas de Login e Cadastro.
* **🧭 Navegação Intuitiva:** Barra de navegação inferior (Bottom Navbar) para acesso rápido às seções.

---

## 🛠️ Tecnologias Utilizadas

* **[React.js](https://reactjs.org/):** Biblioteca principal para construção da interface.
* **[Vite](https://vitejs.dev/):** Ferramenta de build rápida e otimizada.
* **[React Router Dom](https://reactrouter.com/):** Gerenciamento de rotas e navegação SPA (Single Page Application).
* **[Lucide React](https://lucide.dev/):** Biblioteca de ícones moderna e leve.
* **CSS3:** Estilização customizada (sem frameworks pesados) para garantir identidade visual única.

## ⚙️ Como rodar o projeto localmente

Se você deseja rodar este projeto na sua máquina, siga os passos abaixo:

### Pré-requisitos
* Node.js instalado (Versão 18 ou superior recomendada).

### Passo a passo

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/SEU-USUARIO/ecomonitor.git](https://github.com/SEU-USUARIO/ecomonitor.git)
    ```

2.  **Entre na pasta do projeto:**
    ```bash
    cd ecomonitor
    ```

3.  **Instale as dependências:**
    ```bash
    npm install
    ```

4.  **Execute o projeto:**
    ```bash
    npm run dev
    ```

5.  **Acesse no navegador:**
    O terminal mostrará o link local, geralmente: `http://localhost:5173`
